# הכנת הכלי לראש השנה 🍎✨
### מסע פנימי יומי בעקבות משנתו של בעל הסולם

אתר אינטראקטיבי ומותאם למובייל להכשרת הלב, זיכוך הרצון ובניית הכלי הרוחני לקראת ראש השנה והימים הנוראים.

---

## 🌟 מאפייני האתר
- **תוכן מקורי ואותנטי:** לימוד ישיר מתוך מאמרי בעל הסולם ("שמעתי", אגרות ומאמרי סיום הזוהר).
- **התאמה מלאה לטלפונים ניידים (Mobile Responsive):** חוויית קריאה ותרגול חלקה בסמארטפון ובמחשב.
- **שלושה מצבי תצוגה:**
  - ☀️ **מצב יום:** קריאה בהירה ונקייה.
  - 📖 **לימוד חם:** גווני קלף נעימים ללימוד מסורתי.
  - 🌙 **מצב לילה:** קריאה כהה ומרגיעה בעיניים לשעות הלילה.
- **תרגול מעשי ויומן אישי:**
  - שדות כתיבה ובירור עצמי (שנשמרים אוטומטית במכשיר של המשתמש ב-LocalStorage).
  - כפתור **הורדת קובץ תשובות (TXT)** ישירות לטלפון/מחשב.
  - כפתור **העתקה מהירה** להדבקה ב-WhatsApp או ביומן אישי.
- **הסברי עומק אינטראקטיביים:** פירוק מושגי יסוד קבליים ("דבקות בחיי החיים", משל האיבר והגוף ועוד).

---

## 🚀 הפעלה באמצעות GitHub Pages
ניתן להפעיל את האתר בחינם דרך **GitHub Pages**:
1. היכנס להגדרות ה-Repository ב-GitHub (`Settings`).
2. גש ללשונית **Pages** בתפריט השמאלי.
3. תחת **Build and deployment -> Branch**, בחר ב-`main` ושמור (`Save`).
4. תוך כדקה תקבל קישור אינטרנטי ציבורי שניתן לשלוח לכל אדם ולפתוח ישירות מהטלפון!
